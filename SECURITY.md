# Security

Kitroom edits AI tool configuration on your computer, so security reports are taken seriously.

**Please do not open a public issue for security problems.** Report privately through
[GitHub Security Advisories](https://github.com/dev-aiden/kitroom/security/advisories/new).

What the app is designed never to do:

- call AI APIs or ask for API keys;
- read, copy or send CLI login, token or auth files;
- write a user config file without a preview and a backup;
- talk to any server other than the GitHub release check (which can be turned off in Settings).

A report showing any of these can happen is especially welcome.
