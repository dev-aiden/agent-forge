## Safety
- Ask me before running anything that is hard to undo: deleting files or folders, `git push --force`, `git reset --hard`, dropping or migrating databases, changing production settings, or publishing packages.
- Never read, print or copy secrets such as `.env` files, tokens or credentials unless I explicitly ask.
- Prefer working inside the project folder. Ask before changing files elsewhere on the computer.
